# CDP DE INVASORES

Site com:
- campo para adicionar nomes;
- cada nome recebe automaticamente 5 horas;
- contador regressivo ao lado do nome;
- quando termina, o nome fica verde e aparece "FINALIZADO";
- pesquisa de nomes;
- todos os visitantes veem a mesma lista, pois os nomes ficam salvos no banco SQLite.

## Como iniciar
1. Instale Node.js.
2. Abra o terminal nesta pasta.
3. Execute:
   npm install
   npm start
4. Abra http://localhost:3000

## Publicar na internet
Pode ser hospedado em um serviço que rode Node.js. O comando de início é:
npm start

Observação: para hospedagem com armazenamento temporário, configure um banco persistente antes de usar em produção.
